# rishikkasula.github.io

My portfolio site. One HTML file, no framework, no build step.

The design language is borrowed from Apple's product pages: chapter headlines, one-word eyebrow labels, big stat stacks, a single accent color, and footnotes for the claims that deserve receipts. Scroll reveals are a small IntersectionObserver; the stat counters are about ten lines of vanilla JS. The portrait is a WebP with a PNG fallback.

Open `index.html` in a browser to run it locally. Deployed with GitHub Pages.
